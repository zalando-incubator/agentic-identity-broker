Verdict: The classification and detector code fails closed as specified. However, the recommended unsigned-agent predicate `subject_token.sub == request.agent_id` restricts nothing, and six separate documents and contracts still describe the pre-A13 model ("unsigned is always human / signed-only exemption") or a withdrawn migration guide.

Probe coverage:
- A (value matrix): Classification reads raw `subject_claims.sub`. Delegation reads the extracted `subjectID`. The mint reads `res.subject`, which is the target UUID for agents. The detector reads raw `sub` and `agent_id`. Downstream exchange and approvals read `principal_expression` and `agent_id_expression` outputs. Every divergence I found is the documented ADR 045 decision 1/Negative behavior.
