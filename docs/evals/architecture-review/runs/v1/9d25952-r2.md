Verdict: the classification, eligibility, cross-agent and third-party denial checks act on the same values that are minted and looked up downstream. However, the predicate example recommended for unsigned agent subjects constrains nothing, many documents still say unsigned subjects are always human (the code now classifies them as agents under FR-003a), and the default detector also catches broker `client_credentials` tokens, which no document mentions.
