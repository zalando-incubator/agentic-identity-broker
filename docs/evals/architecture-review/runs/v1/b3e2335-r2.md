Verdict: the code follows ADR 045 decisions 2a, 2b and 6/6a on every input I probed, and I found no forbidden token outcome. Many docs still describe the pre-2a rule that unsigned subjects are always human. The shipped unsigned examples' `subject_token.sub != ""` now meets the agent-binding check without limiting anything. The cross-agent statements are broader than what the code enforces in two ways: unbound unsigned subjects, and mapped principals on self-agent requests.
