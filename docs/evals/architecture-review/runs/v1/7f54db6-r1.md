Verdict: the code follows FR-003a, but many operator-facing docs still say unsigned subjects are always human, and the shipped unsigned predicate example passes the `sub` binding check vacuously. Together these let an operator who follows the docs enable consent-free agent issuance for any registered agent without realising it. Separately, the cross-agent check does not cover the extracted principal on an exact-target subject.
