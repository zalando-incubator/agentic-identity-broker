# Agentic Identity Broker Design System

Welcome to the **Refined Trust Architecture** design system for the consent management frontend.

## Current authority

`docs/DESIGN_PRINCIPLES.md` defines the current visual direction.
ADR 037 remains Proposed. The neutral-blue OKLCH design is a proposal, not the current runtime.
The examples here describe Refined Trust Architecture, not constitutional aesthetic requirements.

Principle XI requires centralized semantic tokens, reusable components, and WCAG 2.1 AA.
Every component story must render and pass the accessibility addon in light and dark themes.
Self-host brand assets. Do not load fonts, scripts, or images from third-party origins.

After ADR acceptance, update this guide and all linked design guides in the same implementation cutover.
Do not introduce redesign phases, feature flags, or compatibility paths.

## Overview

This design system provides a comprehensive component library optimized for capturing consent from non-technical end-users who delegate permissions to AI agents. Every component is designed to communicate **trustworthiness, clarity, and control**.

## Design Philosophy

### Refined Trust Architecture

The aesthetic blends the visual gravity of a **bank vault** with the approachability of **modern SaaS**. This is where users make critical decisions about AI agent permissions, so every pixel must communicate authority and trust.

**Core Principles:**

- **Serif Authority with Warm Humanity**: Crimson Pro (serif) for headings creates trust, Manrope (sans) for body text adds approachability
- **Color as Semantic Signal**: Navy for authority, Emerald for success, Amber for attention
- **Elevation Through Shadow**: Multi-layer shadows create depth without borders
- **Motion That Guides**: Purposeful animations (150-500ms) that guide without entertaining
- **Whitespace as Luxury**: Generous padding and spacing create a premium feel

## Color System

### Semantic Tokens

- **trust-deep** (#0A2540): Primary actions, critical UI
- **trust** (#1E4D6B): Medium authority elements
- **trust-light** (#E8F1F5): Light backgrounds
- **cta** (#D97706): Call-to-action buttons, warnings
- **success-primary** (#059669): Success states, granted permissions
- **error-primary** (#DC2626): Error states
