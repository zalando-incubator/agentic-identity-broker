# Plan review — 2026-09-22

Review of the Phase 0/1 artifacts against the code on `038-activity-audit-experience` (HEAD
`eda7b10`) and against current audit-activity UX practice. Each finding lists the change made in
this revision. Severity: **B** blocking (plan not implementable as written), **S** significant,
**U** UX completeness.

| # | Sev | Finding | Change |
|---|---|---|---|
| A1 | B | Emission seams assumed by §11 do not exist: no session/approval expiry detection (lazy on read only); no denial reason codes and revocation deletes the grant; `TokenIssued` does not cover RFC 8693; approval create is idempotent (`IsNew`). | Phase 0 added (typed `DenialReason`, `Exchange` success hook, `IsNew` guard); seam table rewritten with verified file refs; lazy expiries use `occurred_at = expires_at`. |
| A2 | B | FR-016b (one event per action) had no mechanism; the same action reaches the broker repeatedly (per-replica extproc caches, TTL evictions, 5 s retry, lazy detection). | `dedup_key` + `UNIQUE (principal, dedup_key)`; idempotent upsert; key table per type (data-model §1.1). |
| A3 | B | "Summarize into milestones" was asserted, not designed; a busy agent would produce hundreds of identical cards. | Roll-ups: one event per actor/service/bucket with `occurrence_count` (§1.2); roll-up card UX. |
| A4 | B | Prune relies on a scheduler that does not exist; no multi-replica coordination. | Advisory-lock coordinated bounded prune from the recorder drainer (Decision 8). |
| A5 | B | "Log and swallow" loses security-significant events silently; FR-016a asks for a recorded operational error; sync insert on the exchange hot path. | Two recorder modes: in-transaction where a tx exists; bounded async queue + `activity_events_dropped_total` elsewhere (Decision 12). |
| A6 | B | Routes in plan/contract/quickstart were stale (`/consent`, `/agent/:id`, `/oauth2/sessions`); nav active-match is exact. | All routes corrected to the root-mounted SPA; prefix match; server-side route allowlist + client guard. |
| B1 | S | Single persisted `thread_key` at emit time; events belong to several narratives; UTC day baked into storage. | Threads derived on read from `related_refs`; day grouping is client-side in local time. |
| B2 | S | Thread `event_ids` only cover the page; detail `sequence` unbounded. | `total_events` + `truncated`; `sequence_limit` + `sequence_truncated`. |
| B3 | S | Per-event `needs_attention` requires a live join per row; feed filter semantics undefined. | Removed from `ActivityEvent`; filter defined as "refs a current attention subject". |
| B4 | S | `reconnect_required` ignores refresh failures (upstream revocation/rotation). | Derivation includes latest `session.refresh_failed` newer than last success. |
| B5 | S | Approved-field clarification had no artifact; `context` was free-form. | `SafeFields` registry per type with deny-list test (Decision 13). |
| B6 | S | SC-005 unreachable with 25-item "Load more" only. | `q=` (pg_trgm), `before=`, `30d` window, collapsed threads, roll-ups. |
| B7 | S | Correlation id available (OTel) and unused. | `correlation_id` stored, never serialized. |
| B8 | S | Cursor not bound to filters; `format: uuid` vs non-UUID ids; route precedence. | Filter-hash in cursor → `400 invalid_cursor`; ids untyped strings; attention route registered first + test. |
| C1 | U | 7-day retention undermines the trust goal; cliff unexplained. | Default 30 days (spec clarification, pending sign-off); `retention_days` + footer. |
| C2 | U | Attention band can become a wall. | Max 3 visible, `group_key` grouping, oldest first. |
| C3 | U | "Why" was an unstructured string. | `Explanation {trigger, basis, consequence}`; basis doubles as back-link; wording templates written before code. |
| C4 | U | No "don't recognise this?" affordance. | Secondary link to the agent page (where revoke already lives); no new mutation. |
| C5 | U | On-load-only attention band offers dead next steps. | Poll `/attention` every 30 s while visible; revalidate on focus. |
| C6 | U | Non-visual equivalents underspecified beyond Timeline. | Landmark/heading/live-region map in the UX section. |
| C7 | U | Filter bar dense; no active-filter indication; no click-to-filter. | Facet chips, active-filter chips with live count, click-to-filter on card labels; inbound "View activity" links. |
| C8 | U | No scope delta on grant updates; no client context; empty state lacks a pointer. | `scope_added/removed` context; `client_id` ref; empty-state CTA. |
